# PutnamBench Isabelle Formalization Fixes

Date: 2026-06-12. A 50-agent audit of all 639 PutnamBench Isabelle
formalizations (each statement desugared to its raw term — fully
qualified constants, explicit types — and compared against the English
original) confirmed 63 defective formalizations (35 wrong, 28 with
major issues), every finding adversarially verified by an independent
agent.

This report records the corrections. Pipeline: 13 proposer agents
(minimal-change principle, PutnamBench conventions preserved) →
deterministic elaboration check of every corrected theory in its own
import environment (63/63 pass) → an independent adversarial fidelity
review of each corrected statement, again at the desugared-term level
(63/63 good: original defect gone, no new issues).

Impact: applying these corrections changes the benchmark data;
goal-gate baselines and the divergence golden putnam_data_sha are
refreshed deliberately, and evaluation results are not comparable
across the change.

## Corrections

### putnam_1963_b6  (major_issue · high confidence)
- **Defect**: The English requires only that A_0 be nonempty (possibly infinite). The formalization uses 'card (A 0) > 0', which for a set is true only when A 0 is both finite and nonempty (card of an infinite set is 0). This silently adds a finiteness hypothesis, so the theorem proven covers only finite initial sets, a strictly weaker claim than the original.
- **Fix**: Replaced the hypothesis hA0 : "card (A 0) > 0" with hA0 : "A 0 \<noteq> {}".
- **Rationale**: In Isabelle/HOL the card of an infinite set is 0, so card (A 0) > 0 is equivalent to (A 0 \<noteq> {} \<and> finite (A 0)) (card_gt_0_iff). This silently restricted the theorem to FINITE initial sets, a strictly weaker claim. The English (and the Lean ground truth, Nonempty (A 0)) requires only that A_0 be nonempty, including infinite sets such as lines or balls in the \<le>3-dim space. A 0 \<noteq> {} captures exactly nonemptiness with no finiteness rider.
- **Validation**: elaborates (ok); review: good
